# Miya Kasa Defteri

Telefonda çalışan, hesap gerektirmeyen günlük ciro, alışveriş ve kâr takip uygulaması.

- Kayıtlar yalnızca telefonun tarayıcı hafızasında tutulur; hiçbir sunucuya gönderilmez.
- "Yedeği telefona kaydet" düğmesi `miya-yedek-YYYY-AA-GG.json` dosyasını telefonun İndirilenler klasörüne kaydeder.
- "Yedekten geri yükle" ile bu dosyadan kayıtlar geri alınır (yeni telefona taşımak için de kullanılır).
- İlk açılıştan sonra internet olmadan da açılır.

## Yayınlama (GitHub Pages, bir kez yapılır)

1. GitHub'da depoyu açın: Settings → Pages.
2. "Build and deployment" altında Source: **Deploy from a branch**.
3. Branch olarak bu klasörün bulunduğu dalı, klasör olarak **/docs** seçip Save'e basın.
4. Birkaç dakika sonra uygulama `https://kiddieplanettv.github.io/desktop-tutorial/` adresinde açılır.

## Telefona kurma

- iPhone (Safari): adresi açın → Paylaş → **Ana Ekrana Ekle**.
- Android (Chrome): adresi açın → ⋮ menüsü → **Ana ekrana ekle** / **Uygulamayı yükle**.

Not: Uygulamayı her zaman ana ekrandaki simgeden açın. Kayıtlar o tarayıcıya bağlıdır; gizli sekmede açarsanız kayıt tutulmaz.
